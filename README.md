## 这是什么

躺在床上的时候想看电脑里那部片子。装 Jellyfin 太重，建 SMB 共享要折腾权限，插数据线太麻烦。

这个工具只做一件事：**你选几个文件夹或几个文件，它在本机起一个带密码的网页服务，手机连同一个 WiFi 打开地址就能看视频、翻相册、读 PDF 漫画。**

没有账号体系，没有媒体库，没有转码队列。关掉窗口服务就停了，什么都不留在系统里。

## 功能

| | |
|---|---|
| **自由指定内容** | 可以添加任意多个文件夹，也可以单独挑几个视频、照片或 PDF；配置会保存，下次打开还在 |
| **手机优先的页面** | 竖屏排版、文件名自动截断、跨所有位置搜索 |
| **照片墙** | 目录里的图片自动生成缩略图网格，点开全屏查看，左右滑动翻页 |
| **PDF 漫画** | PDF 逐页渲染成图片，全屏阅读、左右滑动翻页、跳到指定页，翻过的页会缓存 |
| **密码保护** | 未登录只能看到登录框；浏览器记住 30 天；连续输错 5 次锁定 60 秒 |
| **能拖进度条** | 实现了 HTTP Range，快进倒退不用重新缓冲整个文件 |
| **MKV 有出路** | 浏览器解不了的容器，播放页给出带凭据的 VLC 直链，粘进去就是原画质 |
| **转码缓存** | 装了 ffmpeg 后，电脑把不兼容的片子转成带索引的 MP4 并缓存，手机浏览器里能像本地文件一样拖 |
| **缓存位置可选** | 转码缓存默认放在 `%LOCALAPPDATA%`，可在界面里改到任意磁盘，并随时查看占用 |
| **零第三方依赖** | 只用 Python 标准库 + Tkinter，不需要 ffmpeg、不需要浏览器驱动（装了 Pillow 会自动启用缩略图） |

## 快速开始

### 1. 准备

- Windows 10 / 11
- Python 3.10 或更高版本（[下载](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**）

### 2. 启动

下载后解压，双击 `手机看视频.bat`。如果电脑已经装了 Python，也可以直接双击 `phone_video_app.pyw`（不会弹控制台窗口）。

```bat
pythonw phone_video_app.pyw
```

### 3. 使用

1. 点 **添加文件夹** 选一个剧集或相册目录，或点 **添加视频/照片** 挑几个散装文件
2. 设一个访问密码
3. 点 **启动服务**，窗口下方出现形如 `http://192.168.1.8:8000` 的地址
4. 手机连同一个 WiFi，浏览器输入这个地址，输密码即可

> 首次启动如果弹出 Windows 防火墙提示，勾选「专用网络」并允许。

## 支持格式

| 格式 | 手机浏览器 | 建议 |
|---|---|---|
| MP4 / H.264 | ✅ 直接播 | 页面标注「可直接播」 |
| WebM | ✅ 直接播 | — |
| MKV / HEVC / AVI / RMVB | ⚠️ 常见只有声音或黑屏 | 播放页提供两条路：复制直链交给 VLC 串流，或直接下载到手机 |
| JPG / PNG / GIF / WebP / BMP | ✅ 直接看 | 目录里自动排成缩略图网格 |
| PDF | ✅ 逐页渲染 | 自动调用 poppler 渲染成图片，体验接近本地阅读器 |

照片支持：JPG、JPEG、PNG、GIF、WebP、BMP、TIFF、AVIF、JFIF。装了 Pillow 时服务端生成 200px 方形缩略图并缓存，没装则直接显示原图。

PDF 需要 `pdftoppm`（poppler）。程序会依次在自身目录、PATH、以及 Codex 运行时的 poppler 目录里找；找不到时退回浏览器内嵌打开 + 下载。

**用 VLC 看 MKV（推荐）**：播放页点「用播放器打开（一键）」，会下载一个 `.m3u` 播放列表，点它选 VLC 即可，不用复制粘贴。看起来像在线看，实际是流式读取 + 手机硬件解码，不占额外存储，拖进度条也正常。也可以「复制直链」，在 VLC 里选「打开网络串流」粘贴。

**下载到手机**：播放页还有「下载到手机（N GB）」按钮，存成文件后用系统相册或本地播放器打开，由系统硬解。适合地铁上没网的时候看，代价是占空间、传输慢。

**转码缓存**：装好 ffmpeg 后，播放页会多出「③ 做成能在浏览器里拖动的版本」。电脑在后台处理一次并缓存到本机：

- 片子本身是 H.264（比如套着 MKV 壳的）→ 只换容器，几秒完成，画质无损
- 其他编码（HEVC、RMVB、10bit）→ 用显卡重新编码，10bit 会压成 8bit 保证浏览器能播

转好的是一个带索引的 MP4，手机浏览器里可以随意拖动，和本地文件没区别。缓存 7 天或超过 40 GB 自动清理。

```powershell
winget install Gyan.FFmpeg
```

程序启动时会在同目录和 PATH 里找 `ffmpeg.exe`，并自动探测 `h264_nvenc`：NVIDIA 卡走硬件编码，几乎不吃 CPU；没有则退回 libx264。把 `ffmpeg.exe` 直接丢到程序目录里也能用（便携版）。

## 安全说明

这个工具的设计前提是**只在自己家用的局域网**。下面把能力边界写清楚，避免误解。

**已经做到的**

- 只监听局域网，代码中没有任何端口映射或外网穿透，公网访问不到
- 所有页面都需要密码，未登录只能看到登录框，看不到任何文件信息
- 连续输错 5 次锁定 60 秒
- 路径做了越界校验，`../` 之类的请求会被拒绝
- 只列出视频扩展名，其他文件不会出现在页面里

**做不到的**

- 传输是明文 HTTP，同一网络下刻意抓包可以看到内容与密码
- 密码以明文保存在 `%APPDATA%\PhoneVideo\config.json`
- 不适合部署到公网，它对恶意访问没有防御能力
- 电脑锁屏、睡眠或断网时，手机端一律打不开

如果需要在外面访问，请使用 [Tailscale](https://tailscale.com/) 这类隧道工具，或换用带远程访问能力的成熟媒体服务器。

## 常见问题

<details>
<summary>手机打开一直转圈，最后提示无法访问</summary>

依次排查：两台设备是否在同一个 WiFi（注意别连「访客网络」，它通常隔离设备）→ 防火墙是否放行了 Python → 窗口里的地址是否输对。
</details>

<details>
<summary>MKV 只有声音没有画面</summary>

不是手机解不了，是浏览器不负责这件事。浏览器对 MKV 容器和 HEVC 编码支持很差，但手机芯片里的硬件解码器是完整的。

两种办法：

1. **串流（推荐）**：播放页点「复制直链」，用 VLC 打开网络串流。播放器调用硬件解码，不占空间。
2. **下载**：播放页点「下载到手机」，存成文件后用本地播放器打开。

如果 VLC 依然卡顿，进「设置 → 视频 → 硬件解码」确认选的是「自动」或「全速」。另外 2.4G WiFi 通常只有 5–8 MB/s，码率高的大片建议连 5G 频段。
</details>

<details>
<summary>转码、串流、下载，到底选哪个</summary>

- **串流到 VLC**：不占手机空间、画质无损、电脑不耗电，缺点是要装 App。日常首选。
- **下载到手机**：最稳，适合离线。缺点是要传输时间 + 手机存储。
- **转码缓存**：手机什么都不用装，浏览器里能随意拖。代价是要先等电脑转一次（H.264 只需几秒），转好的文件占电脑磁盘，7 天后自动清理。

注意：串流时手机已经是在硬解了，电脑只负责传文件；只有手机完全解不了的编码，才需要电脑转码。
</details>

<details>
<summary>能不能用 4G 在外面看</summary>

不能。地址是内网地址，只在本机所在网络内有效。需要远程访问请用隧道工具，不建议直接做端口映射。
</details>

<details>
<summary>会不会被同一 WiFi 下的人看到</summary>

他们能看到登录页，但看不到任何文件名，除非知道密码。想更保险，可以让手机开热点、电脑连热点，这样网络里只有两台设备。
</details>

## 打包成 exe（可选）

想发给没有装 Python 的朋友，可以把程序打包成单文件 exe。最省事的方式是双击 `tools\打包成exe.bat`，它会自动安装 PyInstaller 并完成打包。

也可以手动执行：

```bat
pip install pyinstaller
pyinstaller --noconsole --onefile --icon icon.ico --add-data "icon.ico;." phone_video_app.pyw
```

生成 `dist\phone_video_app.exe`，约 12–15 MB，双击即用。程序已经兼容 PyInstaller 的 `_MEIPASS` 路径，图标和同目录的 `ffmpeg.exe` 都能正确找到。

## 技术说明

整个程序是一个文件：

- `ThreadingHTTPServer` 提供：`/`（位置列表）、`/browse`（目录）、`/play`（播放页）、`/photo`（看图）、`/pdf`（PDF 阅读器）、`/pdfpage`（逐页渲染）、`/thumb`（缩略图）、`/search`（搜索）、`/stream`（文件流）、`/download`、`/convert`（转码缓存）
- 认证走 Cookie（浏览器）与 HTTP Basic（VLC 等播放器）双通道
- `/stream` 手动解析 `Range` 请求头并返回 `206 Partial Content`，这是进度条能用的原因
- 界面用 Tkinter，服务跑在后台线程，关闭窗口即停止
